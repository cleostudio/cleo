Cleo is not a personal homepage. It is a quiet place to learn about the world
and the sky — then ask follow-up questions without leaving the site. The
ambition is modest on purpose: a small English-only portal that treats
knowledge as something you can return to, not a feed you skim once.

We built Cleo as a doorway into two shelves that already feel complete enough
to explore — countries and space — with writing, a shared gallery, and an
agent that knows those same catalogs. Nothing here asks you to create an
account. Nothing tracks you. The pages are meant to read like paper you can
keep open beside a map.

## Portal

The homepage is a doorway, not a dashboard. Search a country, open a highlighted
place, or pick a topic. From there the site stays deliberately small:

- [Explore](/explore) — evergreen country field guides
- [Space](/space) — Solar System, moons, and deep-space primers
- [Gallery](/gallery) — photographs from both catalogs
- [Topics](/topics) — the growing subject list
- [Writing](/blog) — essays that explain how the portal works
- [Cleo](/cleo) — the AI agent on this same site

Each route has one job. Explore orients you to a country. Space orients you to
a body. Gallery lets photographs lead. Topics names the doors. Writing holds
the longer explanations. The agent is for conversation when a static page is
not enough. We keep those jobs separate so the first viewport of any surface
still reads as one composition.

If you arrive from an old bookmark, a few redirects already point the right
way: `/photos` lands on Gallery, and `/projects` lands on Topics. The public
chrome stays focused on the living routes above.

## Voice

Pages are curated. Orientation prose for countries is written once, checked for
length and recycled phrasing, and never generated when you load a guide. The
agent can search the web and reason in conversation, but the field guides stay
stable reading surfaces.

That split matters. A guide you bookmark should say the same thing next month.
Photographs ship as static local JPEGs you can zoom without waiting on an
image account. Space primers follow the same calm instinct as Explore —
orientation first, then features, then a short fact plate. Writing, including
this post, is MDX in the repo: an essay layer on the way to a deeper
encyclopedia-like surface, still reviewed before it ships.

Cleo itself — the agent at [/cleo](/cleo) — is the flexible layer. It can
deep-link real paths into Explore and Space, embed matching curated photos as
Markdown, and chase questions the field guides deliberately leave open. It
runs on OpenAI only. Conversation state lives in your browser and clears on
reload.

## Start

If you want a place, open [Explore](/explore). If you want the sky, open
[Space](/space). If you want to talk it through, open [Cleo](/cleo) and ask.

A useful first hour might look like this: search a country from the homepage,
read the orientation, zoom a contact print, then wander [Gallery](/gallery)
until a Space frame catches you. Open that body’s guide. When two subjects
want comparing, bring the question to the agent and let it name the real
routes — Japan beside Kenya, Mars beside Europa — instead of inventing URLs.

We hope the portal feels quiet enough that you notice what you came for. Cleo
is here when the next question arrives.
