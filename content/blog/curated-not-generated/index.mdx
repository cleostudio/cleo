A knowledge portal can feel cheap the moment every page reads like the same
model filled in a template. Cleo draws a hard line: guides are curated;
conversation is generated.

## Line

Country orientation lives in a maintained prose corpus. Drafts are checked for
length, recycled phrasing, and claims that go stale quickly. No sentence may
appear in two countries. The site never calls a model to render an Explore
page.

Space primers follow the same editorial instinct — stable orientation and
features, not a regenerated summary on each visit.

## Why

Readers should trust that a guide they bookmark next month still says the same
thing. Editors should be able to review every claim. And the AI agent stays
useful precisely because the rest of the site is not improvising underneath it.

## Agent

[Cleo](/cleo) may search the web, reason, and answer in the moment. That is the
right place for freshness. When the durable answer already exists as a field
guide, the agent links to it instead of replacing it.
